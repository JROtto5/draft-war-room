# Architecture

Static, no-build PWA. Four files ship to the browser:

| file | role |
|---|---|
| `index.html` | shell: header, panels, modals, lock screen |
| `styles.css` | theme via CSS custom properties (dark/light), self-hosted fonts |
| `data.js` | generated by `tools/enrich.py` — `RAW` (players), `INTEL`, `PSOS`, `HEADSHOT`, `PLAYERMETA`, `LASTSZN`, `PROJ26`, `TEAMQB`, `INJBASE` |
| `app.js` | everything else |

## Data shapes
- `RAW` row: `[name, team, pos, ppr6, half6, adp, passTD]` — projections stored at 6-pt pass TD; 4-pt and custom PPR/TE-premium are derived (`receptions = (ppr−half)×2`).
- State `S` (localStorage, `v`-stamped, migrated on load): `taken{}`, `mine[]`, `log[{id,who,t}]`, `keepers{}`, `queue[]`, `notes{}`, `dnd{}`, `overrides{}`, `settings{}`, `slotNames{}`, `pickOffset`.
- Pick order → slots: overall pick `n`, round `r=⌈n/teams⌉`, slot = snake fold. `teamRosters()` reconstructs every roster from the log; keepers merge in.

## Engine (per board state, memoized behind `stateKey()`)
VORP vs league-size replacement → saturation (`satAdjust`) → need pressure/locks → stacks → intel/injury/tier-cliff modifiers. Monte Carlo (`survivalOddsRaw`, 30 seeded sims) shares one CPU model (`cpuPick`, seeded from the real log) with mocks (`runMock`). Derived: dual-horizon survival %, per-position pace, VONA, threat board, standings, capital.

## Live layers
ESPN injuries/news + Sleeper trending fetched at runtime (CORS-open, no keys), 5-min polls with backoff, cached 6h; `INJBASE` baked as offline fallback. CSP restricts connect/img to those hosts.

## Tests
`tests/data.test.mjs` (generated-data invariants) · `tests/logic.test.mjs` (engine in a Node VM with a proxy DOM) · `tests/build-e2e.mjs` + headless Chrome (`?e2e` disables network side-effects) · `scripts/lint.mjs` (structure + size budgets). All run in CI.

## Annual refresh
`./tools/refresh.sh proj.csv board.csv [season]` regenerates `data.js`, bumps the SW cache, runs tests. `tools/release.sh <ver>` tags releases.
