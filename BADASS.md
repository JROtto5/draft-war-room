# BADASS.md — the v16 stack

## 🖥 War Room Mode (B)
Fullscreen Sunday cockpit: giant score + win dial, my nine and theirs with real
game clocks, a rotating intel panel (broadcast → standings → rooting → wire →
future), and the plan. Wake lock, F for true fullscreen, 1–4 focus, R rotate,
Space pause, Esc out. Listens by default.

## 🎙 The Voice
"Score" · "read me the plan" · "brief me" · "playoff odds" · "should I start
X" · "start X for Y" (stages it) · "war room" · "waivers" · "scout". Speaks
back with swagger scaled to the hype dial; optional wake phrase; a typed ask
box does the same thing where speech recognition doesn't exist.

## 📢 The Arsenal
Power rankings (text + PNG) with data-backed roasts, the weekly newsletter,
per-opponent smack. Commissioner-safe toggle, joke log so nothing repeats,
Tuesday auto-fire. Every claim traces to a real stat.

## 📺 Broadcast
Live scoring feed from ESPN summaries (throttled, only relevant games), red-zone
strip, lead-change horns, and the week's highlight reel. All audio behind the
existing sound settings.

## 🏛 The Vault
League records, personal bests, hall of fame/shame, head-to-head, film room,
vault search, dynasty snapshots, JSON export.

## 🧠 Edge Radar
Breakouts, buy-low/sell-high, schedule arbitrage, playoff alpha, crowd fades —
ranked by value × confidence, each linked to the actual move.
