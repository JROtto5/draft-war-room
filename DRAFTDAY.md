# Draft-day runbook

**T-30 min**: open the site, hit `?` for the checklist, 🧯 run the offline
drill once (everything must keep working), settings → confirm slot/timer/
sound, arm 🔄 Sync if the draft is on Sleeper, second screen → `?wall`.

**Kickoff**: flip 🔴 LIVE (wake lock + chime + panic + pace clock on).

**During**: sync marks picks itself, or you do (M/T on rows). Queue with Q;
your plan pings you on the clock. `P` grabs queue-top instantly. Watch the
pills: LEFT / SHELF / BY-#N / run flames. ⏩ sim-to-my-pick if solo-mocking.

**If the browser dies**: reopen — everything is saved; a toast confirms Live
is still armed and which pick you were on. The IndexedDB mirror backs the
backup. Two tabs both LIVE will warn you.

**After pick 16**: confetti → report → 😈 taunt → 🏁 "finish the room" fills
the last CPU picks so standings and awards are complete.
